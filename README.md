# SNN-Analysis
Analyzing SNNs with LLMs

## Setup
This project uses the OpenAI API, meaning you will need to do the following:  
- Follow steps to get API key https://platform.openai.com/api-keys
- Set your api key as an enviornment variable `OPENAI_API_KEY`
- `pip install -r requirements.txt`  *recommend using a virtual environment*

## sample
The sample scripts are from the openai dev website to check that your API key is setup, and everything is functioning.
